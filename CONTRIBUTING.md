# Contributing

## Adding a headline

1. Fork, or just edit `index.html` in the GitHub web editor.
2. Find the `<div class="two-up">` block or the `Briefs` sidebar.
3. Copy the shape of an existing entry:

```html
<article class="story">
  <h3>Your Headline In Title Case, Under Twenty Words</h3>
  <p>One sentence underneath that makes it land harder.</p>
</article>
```

4. Open a pull request. Put the joke in the PR title so it is funny before anyone
   even reviews it.

## What gets merged

Anything that is true, affectionate, and specific.

## What does not

- Anything about a named real person
- Anything about a real client or nonprofit
- Anything that would read as an official 180DC statement
- Anything mean

The whole premise only works if a member of the club would laugh and then send it
to the group chat.
